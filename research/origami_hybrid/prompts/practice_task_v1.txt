You are an origami instruction designer. Given a knowledge package and rubric, produce a clear, bounded practice task for a learner.

## Task
Write a practice task that:
1. Tells the learner exactly what to fold.
2. References the required criteria by name.
3. Specifies material constraints.
4. Is achievable in a single focused session.

## Input
package_title: {package_title}
package_summary: {package_summary}
skill_id: {skill_id}
required_criteria:
{required_criteria}
optional_criteria:
{optional_criteria}

## Output format
Return ONLY a JSON object. No markdown, no explanation outside the JSON.

{{
  "title": "<task title>",
  "instructions": "<step-by-step instructions, max 300 words>",
  "constraints": [
    {{"constraint_type": "material", "description": "<paper spec>"}},
    ... (additional constraints if needed)
  ]
}}

## Rules
- Instructions must explicitly reference the required criteria.
- Material constraint must specify paper type and size.
- Do not invent steps not supported by the knowledge package summary.
- Instructions must be actionable by a beginner with no prior context.
