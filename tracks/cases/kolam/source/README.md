## Local goal pattern asset

- **File:** `ithayakkamalam_target.jpg` (492x499, JPEG); provenance, licence and sha256 in `source.json`
- **Role:** `target_image`, the only input the system uses (goal-conditioned, final image only)
- **Description:** Ithayakkamalam ("heart lotus") kolam: one continuous line drawn **through** the dots, rotationally symmetric. (Not a Sikku kolam, whose lines loop around the dots.)
- **Attribution:** "Ithayakkamalam - 2.jpg" by Mayooranathan, public domain, via Wikimedia Commons
- **Held-out images:** `held_out/` (see `source.json`)
