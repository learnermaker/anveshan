# Track B Source Boundary

Implementation for practice, evaluation, feedback, measurement, and lineage belongs here.

Keep auditable responsibilities deterministic:

- rubric aggregation;
- score/change calculation;
- state transitions;
- provenance/lineage checks.

Model assistance may support observation, comparison, or feedback generation, but the authoritative evaluation path must remain inspectable and replayable.

No framework or service is selected by this starter file.
