## How to Use This Dossier

When considering a new feature or direction:

1. Check the feature universe.
2. Check competitive landscape.
3. Check rejected directions.
4. Check the exploration record.
5. Check open questions.
6. Check the canonical product and MVP documents.
7. Only then create or update a product decision.

This prevents repeated exploration and accidental loss of prior reasoning.
