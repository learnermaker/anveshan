# Access Control Model

## Access Levels

### Private

Only the contributor or explicitly authorized people.

### Family

Accessible to approved family members.

### Community

Accessible to authorized members of the relevant community.

### Approved Learners

Accessible to learners approved for the relevant knowledge.

### Institutional

Accessible within an organization.

### Public

Generally accessible.

### Research-only

Accessible under a defined research agreement.

## Permission Dimensions

Permissions may govern:

- source media
- transcript
- extracted knowledge
- evidence
- lessons
- learner attempts
- lineage
- community metadata
- generated outputs.

## Enforcement

Permission checks should occur:

1. before retrieval;
2. before tool access;
3. before model context construction;
4. before generation;
5. before sharing.

## Principle

A model having technical access to a source must not be treated as authorization to disclose it.
