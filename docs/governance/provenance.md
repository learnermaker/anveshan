# Provenance Model

## Source Hierarchy

1. Original source media.
2. Directly observed evidence.
3. Structured claim.
4. AI interpretation.
5. Community interpretation.
6. Generated teaching material.

## Claim Record

A claim should ideally retain:

- claim ID
- source ID
- speaker
- timestamp
- modality
- original language
- context
- location
- date
- evidence type
- support status
- contradiction status
- interpretation
- reviewer
- verification state.

## Evidence States

- direct
- demonstrated
- observed
- corroborated
- disputed
- inferred
- unverified
- unknown.

## Provenance Requirements

Important generated outputs should be able to answer:

- What source supports this?
- Where in the source?
- Who said or demonstrated it?
- Under what conditions?
- Is this directly stated or inferred?
- Are there conflicting sources?
- Has a human reviewed it?

## Immutable Source Principle

Do not modify original source media to incorporate AI-generated content.

Derived objects may be revised while preserving their history.

## Auditability

Record significant:

- ingestion events
- transformations
- reviews
- corrections
- permissions
- publication changes
- lineage changes.
