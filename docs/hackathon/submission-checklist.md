# Submission Checklist

## Competition

- [ ] Confirm official rules on https://aibuildercup.com/
- [ ] Confirm eligibility.
- [ ] Confirm team details.
- [ ] Confirm team size.
- [ ] Confirm submission deadline.
- [ ] Confirm theme selection.
- [ ] Confirm required Google technologies.
- [ ] Confirm deployment requirements.

## Product

- [ ] Product thesis finalized.
- [ ] MVP domain selected.
- [ ] Real expert confirmed.
- [ ] Real learner confirmed.
- [ ] Real source media captured.
- [ ] Skill bounded.
- [ ] Practice rubric defined.
- [ ] Transmission outcome defined.

## Technical

- [ ] Source capture works.
- [ ] Multimodal processing works.
- [ ] Knowledge extraction works.
- [ ] Evidence grounding works.
- [ ] Search/retrieval works.
- [ ] Teaching flow works.
- [ ] Learner submission works.
- [ ] Attempt evaluation works.
- [ ] Feedback is evidence-based.
- [ ] Retry works.
- [ ] Transmission record works.
- [ ] Lineage works.
- [ ] Permissions work.
- [ ] Logging/observability works.
- [ ] Deployment works.
- [ ] Failure handling works.

## Validation

- [ ] Expert reviewed extracted knowledge.
- [ ] Ten difficult evidence questions tested.
- [ ] Evidence citations checked.
- [ ] Practice task reviewed.
- [ ] Learner attempt tested.
- [ ] Feedback reviewed.
- [ ] Baseline measured.
- [ ] Second attempt measured.
- [ ] Transmission Gain calculated where defensible.
- [ ] Known failure modes documented.

## Demo

- [ ] Demo uses authentic source.
- [ ] Demo shows something non-obvious.
- [ ] Demo shows evidence.
- [ ] Demo shows teaching.
- [ ] Demo shows learner attempt.
- [ ] Demo shows verification.
- [ ] Demo shows improvement.
- [ ] Demo shows lineage.

- [ ] README updated.
